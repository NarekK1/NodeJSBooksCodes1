r — только чтение. Курсор устанавливается на начало файла. Если файл не  
существует, генерируется исключение; 
r+ — чтение и запись. Курсор устанавливается на начало файла. Если файл не 
существует, генерируется исключение; 
rs+ — чтение и запись в синхронном режиме. Указывает операционной системе 
не использовать кэш. Курсор устанавливается на начало файла. Если файл не 
существует, генерируется исключение; 
w — запись. Если файл не существует, он будет создан. Если файл существует, 
он будет перезаписан. Курсор устанавливается на начало файла; 
wx — запись. Если файл не существует, он будет создан. Если файл существует, 
генерируется исключение. Курсор устанавливается на начало файла; 
w+ — чтение и запись. Если файл не существует, он будет создан. Если файл су
ществует, он будет перезаписан. Курсор устанавливается на начало файла; 
wx+ — чтение и запись. Если файл не существует, он будет создан. Если файл 
существует, генерируется исключение. Курсор устанавливается на начало  
файла; 
a — дозапись в конец файла. Если файл не существует, он будет создан; 
ax — запись. Если файл не существует, он будет создан. Если файл существует, 
генерируется исключение; 
as — дозапись в конец файла в синхронном режиме. Если файл не существует, 
он будет создан; 
a+ — чтение с начала файла и дозапись в его конец. Если файл не существует, он 
будет создан; 
ax+ — чтение и запись. Если файл не существует, он будет создан. Если файл 
существует, генерируется исключение; 
as+ — чтение с начала файла и дозапись в его конец в синхронном режиме. Если 
файл не существует, он будет создан.
